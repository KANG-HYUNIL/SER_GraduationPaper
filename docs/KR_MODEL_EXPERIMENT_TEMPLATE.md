## 작성 규칙

- 문서 안의 경로는 절대경로를 쓰지 않는다.
- 경로는 모두 현재 문서 기준 상대경로로 적는다.
- 실험 회차는 가능하면 날짜와 출력 폴더를 함께 적는다.
- 결과 표에는 최소 `F1-macro`, `Accuracy`, `UAR`를 포함한다.
- artifact 분석은 관찰과 해석을 구분해서 적는다.
