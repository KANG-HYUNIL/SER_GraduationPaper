## 4. 설계 배경 및 구현 메모

### 4.1 padding-safe 회귀의 의미

- 길이와 mask 안전성을 확보하는 과정 자체는 필요했지만, 이 회차는 구조와 입력 조건까지 함께 바뀌어 성능이 크게 후퇴했다.
- 따라서 “padding-safe 때문에 망했다”가 아니라 “search space 자체가 다른 모델군으로 이동했다”는 해석이 더 적절하다.

### 4.2 이 날부터 정리된 핵심 방향

- `n_mels=80`, `hop_length=160` 같은 논문 친화적 고정 입력
- frequency flatten projector 기반 시퀀스 투영
- relative positional MHSA
- Conformer small-to-medium 범위의 구조 탐색

관련 코드는 메인 문서의 코드 링크를 따른다:

- [KR_MODEL_CNN_CONFORMER.md](../KR_MODEL_CNN_CONFORMER.md)

## 5. 아티팩트 분석 또는 주요 결과

### 5.1 관찰

- padding-safe stage는 성능이 `0.49` 수준으로 내려가며 회귀를 보였다.
- 대신 이 결과가 “무엇을 고정해야 하는지”를 강하게 알려줬다.
  - 입력 표현을 흔들지 말 것
  - backbone 규모를 과도하게 줄이지 말 것
  - mean pooling보다 attention pooling이 우세할 가능성이 높을 것
