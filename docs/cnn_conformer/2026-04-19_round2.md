# CNN Conformer Experiment - 2026-04-19 Round 2

## 1. 문서 범위

- 대상 모델: `cnn_conformer`
- 목적: 2026-04-19 구조 탐색 이후 `layer fusion + loss + sampler` 결합 실험 계획 기록
- 상태: `active`

## 2. 모델 스냅샷

### 2.1 한 줄 요약

이 회차는 2026-04-19 1차 구조 탐색의 승자 backbone을 고정한 뒤, `layer fusion`과 `loss/sampler`의 조합이 감정 혼동을 줄이는지 검증하는 2차 실험이다.

### 2.2 실험 가설

- `learned_sum`은 전층 융합이라 peak를 깎았을 수 있다.
- `last2_mean` 같은 가벼운 late fusion은 저층 acoustic cue를 조금 살리면서도 `last`의 sharpness를 덜 해칠 수 있다.
- 구조를 더 바꾸지 않고도 `weighted_cross_entropy`, `focal_loss`, `WeightedRandomSampler`가 `sad / neutral / calm / happy / fearful` 혼동을 줄일 수 있다.

## 4. 설계 배경 및 구현 메모

### 4.1 1차 실험에서 이어지는 근거

- 1차 구조 탐색 최고점은 `time_preserve_first + last + single + attention`이었다.
- `learned_sum`은 평균은 높였지만 최고점을 못 만들었다.
- confusion matrix 병목은 `sad / neutral / calm / happy / fearful` 경계였다.
- 따라서 2차는 큰 backbone 변경 대신 `layer fusion`과 `학습 objective`를 함께 보는 것이 타당하다.

- `train.sampler.name` 도입

실험 완료 후 아래 관점으로 채운다.

- weighted sampler가 calibration을 악화시키는지
- 최고 F1 조합과 최고 calibration 조합이 다시 분리되는지

## 6. 종합 인사이트 및 다음 액션

### 6.2 다음 액션

- 전반적으로 무효면 구조보다 representation 축, 즉 SSL hybrid를 다음 단계로 검토
